# Portfolio — earlier version

An earlier version of my personal website, built around a phone-inspired landing screen that transitions into a full portfolio. I've since built a newer site, but I'm keeping this version public as a record of the design work and how the site evolved.

**[Original site](https://vandan-patelold.vercel.app/)** · **[Current portfolio](https://vandan-portfolio.vercel.app/)**

## What I worked on

- A phone-style entry experience with drag and animated transitions into the website.
- Light/dark themes that follow system preferences.
- A responsive portfolio layout with sections for projects, experience, and skills.
- Interface details including a dock, animated backgrounds, and project cards.

## Stack

React, JavaScript, Vite, Framer Motion, GSAP, and CSS.

## Run locally

```bash
git clone https://github.com/vp-27/LEGACY-Portfolio-Website.git
cd LEGACY-Portfolio-Website
npm ci
npm run dev
```

This is an **archived-in-practice** version rather than the website I actively maintain. Its content and embedded resume reflect an earlier point in time. The newer site is maintained in [`vp-27/portfolio`](https://github.com/vp-27/portfolio).
